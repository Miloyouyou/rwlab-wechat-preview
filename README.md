# 实验室公众号推文｜公开源码与预览

本仓库公开提供两篇公众号推文的完整静态页面源码、排版样式、复制工具及页面配图。无构建步骤、无数据库、无平台专有运行依赖，可下载后在其他电脑、代码编辑器或 AI 开发平台继续修改。

这是公众号推文工程，不是实验室官网工程；不包含官网后台、数据库、本地研究资料或微信登录信息。实验室官网源码仍保持私有。预览网页更新不等于公众号已发布。

- [实验室团队宣传推文](01_实验室团队/公众号正文.html)
- [RWIA 2026 / CCRW 2026 会议推文](02_RWIA会议通知/公众号正文.html)

网页预览入口：[https://miloyouyou.github.io/rwlab-wechat-preview/](https://miloyouyou.github.io/rwlab-wechat-preview/)。文章页提供“复制排版图文”“复制纯文字”“复制标题”按钮；复制后仍需在公众号后台检查图片、链接及手机预览。

## 1. 下载与本地运行

不登录 GitHub 也可以克隆，或通过仓库的 **Code → Download ZIP** 下载完整工程。

```bash
git clone https://github.com/Miloyouyou/rwlab-wechat-preview.git
cd rwlab-wechat-preview
python3 -m http.server 8080 --bind 127.0.0.1
```

浏览器打开 `http://127.0.0.1:8080/`。Windows 安装 Python 后，可把最后一行替换为：

```powershell
py -m http.server 8080 --bind 127.0.0.1
```

按 `Ctrl+C` 停止预览。直接双击 HTML 可以查看正文，但“复制排版图文”需要通过本地 HTTP 或 HTTPS 网页使用；浏览器还可能要求剪贴板权限。该命令仅用于本地预览，不作为生产服务器。

```text
index.html                      两篇推文的预览入口
publish-helper.css              预览工具栏及适配样式
publish-helper.js               复制排版图文、纯文字、标题等功能

  正文可编辑.txt                 纯文字参考稿
  配图/                         该篇使用的照片、论文图及证书
02_RWIA会议通知/
  公众号正文.html                会议推文正文与排版
  正文可编辑.txt                 纯文字参考稿
  配图/                         酒店、园区、注册二维码、邀请函及封面
```

正式页面以 `公众号正文.html` 为准；只修改 TXT 不会改变网页。正文位于 `article#wechat-article`，排版大量使用内联样式，以便复制到公众号编辑器。修改正文后也应同步相应的纯文字稿。

更换图片时保留相对路径，或同步修改 HTML 中的 `src`。不要只下载单个 HTML 而遗漏配图、CSS 和 JS。目录名含中文，文件统一按 UTF-8 保存。

## 4. 静态部署与公众号编辑

- GitHub Pages 当前从 `main` 分支根目录发布。提交更新后，等待 Pages 构建完成再检查网页。
- 迁移到其他静态托管平台时，不运行构建命令，将仓库根目录设为发布目录；保留子目录与文件名。
- 在文章页点击“复制排版图文”，粘贴到公众号正文编辑区。封面需单独上传，保存后检查手机预览。
- 微信编辑器可能调整表格列宽、图片布局或限制外部超链接。本地网页显示正常不代表微信内一定相同；不要把 HTML/ZIP 当作微信官方直接导入格式。
- 会议注册入口是 <https://wj.sjtu.edu.cn/q/k2WLZVfi>。如正文无法添加外链，可使用注册二维码，并在公众号“阅读原文”处填写该地址。
